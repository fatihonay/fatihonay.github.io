Receptive fields: how to read an image from the brain

22 October 2026 · Simulation · Vision

Pick a card, any card. In 2008, Kendrick Kay and colleagues in Jack Gallant's lab played a version of this magic trick with the brain. A person in an MRI scanner looked at a photo they had never seen before. Using only the brain activity, a computer then picked out which photo it was from a set of 120, and got it right 92% of the time for one person, where guessing would succeed less than 1% of the time (Kay et al., 2008, Nature).

The trick works because of one idea: the receptive field. If we know what each small piece of visual cortex "looks for", we can predict how it will respond to any image, even a new one.

What is a receptive field?

A neuron in visual cortex does not see the whole scene. It responds only to a small patch of the visual field: its receptive field. Within that patch it is also picky about what appears there. A typical V1 neuron prefers stripes or edges at one orientation and of one width (spatial frequency), as Hubel and Wiesel discovered.

So a receptive field answers two questions: where does the neuron look, and what does it look for? Both can be captured by a Gabor filter, a small striped patch that fades out at the edges. The neuron's response is how well the image under the patch matches the stripes. Using two such filters, shifted by a quarter cycle, makes the response depend on the stripes but not on their exact position. This "energy" model behaves like the complex cells from the previous note.

From one neuron to the whole visual cortex

fMRI does not record single neurons. It measures blood flow in small cubes of brain called voxels, each containing hundreds of thousands of neurons. But neighbouring neurons share similar receptive fields, so a whole voxel has a receptive field too, just a broader one. Kay and colleagues showed each person 1,750 natural photos and, for every voxel in visual areas V1, V2 and V3, estimated a receptive-field model of this kind: a set of Gabor filters at different positions, orientations and widths, each with a learned weight.

Then came the card trick. People viewed 120 new photos. For every candidate photo, the models predicted the pattern of activity across all voxels. The computer picked the photo whose predicted pattern best matched (highest correlation) the measured pattern. You can play the same game below with 98 model voxels and 12 images.

Why "where" is not enough

Early visual cortex is laid out like a map of the visual field (retinotopy), so you might think the trick only needs to know where each voxel looks. Kay and colleagues tested exactly this. A model that captured only each voxel's location and size identified images much less well than the full model with orientation and spatial-frequency tuning. The demo shows the same effect: the what part of the receptive field carries much of the information.

The real results were remarkable for fMRI, which is slow and noisy. With 1,000 candidate photos, accuracy for the first person was still 82%. Even two months later, on new photos, it was 82% for a set of 120.

Try it in Python

The core of a receptive-field model fits in a few lines:

import numpy as np

def gabor_pair(wavelength, orientation_deg, size=31):
    """Two Gabor filters a quarter cycle apart (the 'what' of a receptive field)."""
    r = size // 2
    y, x = np.mgrid[-r:r + 1, -r:r + 1]
    theta = np.deg2rad(orientation_deg)
    across = x * np.cos(theta) + y * np.sin(theta)        # distance across the stripes
    envelope = np.exp(-(x**2 + y**2) / (2 * (wavelength / 2)**2))
    even = envelope * np.cos(2 * np.pi * across / wavelength)
    odd = envelope * np.sin(2 * np.pi * across / wavelength)
    return even - even.mean(), odd

def rf_response(image, x0, y0, wavelength, orientation_deg):
    """Energy response of a receptive field centred at (x0, y0) (the 'where')."""
    even, odd = gabor_pair(wavelength, orientation_deg)
    r = even.shape[0] // 2
    patch = image[y0 - r:y0 + r + 1, x0 - r:x0 + r + 1] - image.mean()
    return np.hypot((patch * even).sum(), (patch * odd).sum())

# A stimulus with stripes at 45 degrees, 8 pixels wide
y, x = np.mgrid[0:64, 0:64]
stripes = np.cos(2 * np.pi * (x + y) / np.sqrt(2) / 8)
for ori in [0, 45, 90, 135]:
    print(ori, round(rf_response(stripes, 32, 32, 8, ori), 1))   # peaks at 45

# Identification: correlate the measured voxel pattern with each candidate's prediction
def identify(measured, predicted_patterns):
    r = [np.corrcoef(measured, p)[0, 1] for p in predicted_patterns]
    return int(np.argmax(r))

Why this matters for EEG

Kay's study is an example of an encoding model: describe the stimulus with features, predict the brain response, and test the prediction on data the model has never seen. The same recipe drives a lot of EEG and MEG research. EEG can't resolve small patches of cortex like fMRI, but it follows the brain in milliseconds, so EEG encoding models predict the signal over time from features of sounds, speech or video (as in the video–EEG study by Yao et al., 2024). The better our model of what the brain "looks for", the more we can read from its activity, whether that's for basic science or for brain–computer interfaces.

Note: the demos use 98 simulated voxels, 12 synthetic natural-like images and added noise to show the principle. The real study fitted models to fMRI data from two people and many more voxels, with Gabor filters at many scales and positions.
