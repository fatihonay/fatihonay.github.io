Linear or nonlinear? Solving equations in the brain

15 October 2026 · Simulation · Modelling

Every model in neuroscience is a set of equations. An equation connects what we know (what we measured, or the input we gave) to what we want to find (the brain activity behind it). Solving the equation means finding the values that make the relationship true.

Some of these equations are linear, and some are nonlinear. The difference decides how many answers there can be, and whether we can find them with algebra or need a computer to search for them. Two everyday neuroscience examples show the difference.

A linear example: what an EEG electrode hears

An EEG electrode does not record one brain area. It records a weighted sum of every active source, because electric fields spread through the head (volume conduction). The physics of these fields is linear: if a source becomes twice as strong, its contribution at the electrode doubles, and the contributions of different sources simply add up.

Suppose two sources, s1 (frontal) and s2 (parietal), reach two electrodes with different weights: 

Fz = 0.8·s1 + 0.3·s2 = 9.5 µV
Pz = 0.2·s1 + 0.6·s2 = 5.0 µV

Two equations, two unknowns, and the unknowns appear only multiplied by numbers and added: a linear system. Each equation is a straight line in the (s1, s2) plane, and the answer is where the lines cross: s1 = 10 µV, s2 = 5 µV. Linear systems are friendly: there is exactly one crossing, none (parallel lines), or infinitely many (the same line), and a computer finds it directly.

A nonlinear example: a neuron population that excites itself

Neurons are not linear. Below a threshold they barely fire; above it their firing rises quickly; and it can't rise forever, so it saturates. The firing rate follows an S-shaped curve: doubling the input does not double the output.

Now let a population of neurons excite itself, as cortical circuits do. Its activity r (from 0 = silent to 1 = maximal) feeds back as part of its own input. It settles where the activity it produces equals the activity it receives (a classic model by Wilson and Cowan, 1972): 

r = F(w·r + I)

F: S-shaped firing curve   w: self-excitation   I: outside input

r appears on both sides, inside the curved function F. There is no algebra trick that isolates it. But we can draw both sides and look for where they meet.

Teal line: activity the population has (y = r). Curve: activity it produces, F(w·r + I). Every crossing is a solution. Filled dots are stable, hollow dots are unstable. Click inside the plot to start the population at that activity and watch where it settles.

Try this: slowly raise the self-excitation w from 3 to 8 and lower the input I to about −3. A single crossing splits into three. Now click near the bottom-left of the plot, then near the top-right: the population stays either almost silent or highly active, depending only on where it started. That is memory. Finally, tick "Make the neuron linear": now the two lines cross once at most (or, in one special case, lie on top of each other). Two separate stable states are impossible.

Why three solutions matter

With strong self-excitation the population has two stable states: a quiet one and an active one, separated by an unstable point in between. A brief input can push it from quiet to active, and it stays active after the input is gone, because it keeps exciting itself. Persistent activity of this kind is a leading model of how prefrontal cortex holds an item in working memory for a few seconds. A linear system can never do this: with straight lines, there is at most one crossing.

How does a computer find a solution it can't write down?

Move everything to one side, so the question becomes "where is this function zero?": 

f(r) = F(w·r + I) − r = 0

The button in the demo runs the simplest search, bisection. Find two points where f has opposite signs, so a zero must lie between them. Check the middle, keep the half where the sign still changes, and repeat. Every step halves the interval; after 20 steps the answer is accurate to about one millionth. MATLAB's fzero and Python's brentq use smarter versions of the same idea.

Try it in Python

import numpy as np
from scipy.optimize import brentq

# Linear: EEG mixing, two electrodes and two sources
A = np.array([[0.8, 0.3],      # Fz weights
              [0.2, 0.6]])     # Pz weights
b = np.array([9.5, 5.0])       # measured µV
print(np.linalg.solve(A, b))   # [10.  5.]  (MATLAB: A\b)

# Nonlinear: where does the self-exciting population settle?
F = lambda u: 1 / (1 + np.exp(-u))       # S-shaped firing curve
w, I = 8, -3
f = lambda r: F(w * r + I) - r

r = np.linspace(0, 1, 1001)               # look for sign changes first...
brackets = np.where(np.diff(np.sign(f(r))))[0]
roots = [brentq(f, r[i], r[i + 1]) for i in brackets]   # ...then zoom in (MATLAB: fzero)
print(np.round(roots, 3))                 # [0.099 0.207 0.993]

Why this matters for EEG

Both kinds of problem meet in real EEG research. Finding where a signal comes from in the brain (source localisation) is a linear problem, but with thousands of possible sources and only a few dozen electrodes it has infinitely many solutions, so we must add assumptions to pick one. Models of the rhythms themselves, such as the synchrony in the first Lab Note, are nonlinear, which is exactly what lets them switch between states, oscillate, or, in epilepsy, tip into a seizure.

A computer can calculate an answer, but a scientist must decide whether it is meaningful: which solution is stable, and which one the brain actually uses.

Note: the population model is simplified to show the principle; real models include inhibitory neurons and time constants, and fit their parameters to data.
