Representational similarity analysis: comparing brains and models

29 October 2026 · Simulation · Methods

Suppose you have a computer model of vision with 1,000 artificial neurons, and fMRI data from a brain region with 500 voxels. Which voxel corresponds to which model unit? There is no answer. The same problem appears when you compare two people (their brains are shaped differently), a human and a monkey, or fMRI and EEG (completely different kinds of signals).

Representational similarity analysis (RSA) sidesteps the problem with a simple change of question (Kriegeskorte, Mur and Bandettini, 2008). Instead of asking "what does each channel do?", it asks: which stimuli does this system treat as similar, and which as different? Any brain region, model or measurement can answer that question, and the answers can be compared directly.

The representational dissimilarity matrix

Show a set of stimuli and record the activity pattern each one evokes. For every pair of stimuli, measure how different their two patterns are. The paper's choice is 1 − correlation: 0 for identical patterns, 1 for unrelated ones. Put all these numbers in a table with one row and one column per stimulus, and you get the representational dissimilarity matrix (RDM). It is symmetric, with zeros on the diagonal (a stimulus is identical to itself), and it no longer depends on which voxel is which: it is a signature of what information the region carries.

Comparing a brain region with models

Here is the payoff. A model does not need to have the same units as the brain; it only needs to make a prediction about which stimuli should be similar. That prediction is also an RDM. It can come from a computational model (for example, Gabor filters like the receptive-field note), from a simple category idea ("faces are similar to each other"), or from behaviour (which stimuli people confuse).

To compare two RDMs, RSA correlates their entries above the diagonal. It uses a rank (Spearman) correlation, because we only expect the model to get the order of the dissimilarities right, not their exact values. To test whether the match is better than chance, it shuffles the stimulus labels of one RDM many times and recomputes the correlation each time. If the real match beats almost all shuffled ones, it is unlikely to be a coincidence.

What the paper found

Kriegeskorte and colleagues showed people 96 photos of faces, bodies, animals, objects and places, and computed RDMs for early visual cortex and for the fusiform face area (FFA). In early visual cortex, the best-matching model was simply the silhouette of each image, consistent with a map of the shape that falls on the retina. In the FFA, faces clustered together, and apart from the FFA in the other hemisphere, the best model was a "face–animal prototype" model: all faces evoke a similar pattern, and animals do so to a lesser degree.

The bigger idea is that the RDM works as a common currency. The same matrix can be computed for computational models, behavioural judgements, brain regions, different people, monkeys and humans (Kriegeskorte et al., 2008, Neuron), and different recording methods, and all of them can be compared on equal terms.

Try it in Python

import numpy as np
from scipy.stats import spearmanr

def rdm(patterns):
    """patterns: stimuli x channels. Returns 1 - correlation between every pair."""
    return 1 - np.corrcoef(patterns)

def compare(rdm_a, rdm_b, n_perm=1000, seed=0):
    """Spearman correlation of two RDMs, and a p-value from shuffling stimulus labels."""
    upper = np.triu_indices_from(rdm_a, k=1)            # entries above the diagonal
    r = spearmanr(rdm_a[upper], rdm_b[upper])[0]
    rng = np.random.default_rng(seed)
    null = []
    for _ in range(n_perm):
        p = rng.permutation(len(rdm_a))                  # shuffle the stimulus labels
        null.append(spearmanr(rdm_a[p][:, p][upper], rdm_b[upper])[0])
    return r, np.mean(np.array(null) >= r)

# Toy example: a "face region" whose patterns depend on whether a stimulus is a face
rng = np.random.default_rng(1)
is_face = np.repeat([1, 0], 8)                           # 8 faces, 8 non-faces
face_pattern = rng.standard_normal(50)
brain = np.outer(is_face, face_pattern) + 0.8 * rng.standard_normal((16, 50))
face_model = (is_face[:, None] != is_face[None, :]).astype(float)   # 0 = same category

r, p = compare(rdm(brain), face_model)
print(f"Spearman r = {r:.2f}, p = {p:.3f}")

Why this matters for EEG

RSA is one of the most useful tools for EEG and MEG, because it doesn't care that electrodes and fMRI voxels measure completely different things. With EEG you can compute an RDM from the pattern across electrodes at every time point, and watch when, after the image appears, the brain starts to separate faces from objects. Matching these time-resolved RDMs with fMRI RDMs from different brain regions shows where and when each representation appears, an approach called MEG–fMRI fusion (Cichy et al., 2014). The same matrices can be compared with the layers of a CNN, as in the visual hierarchy note.

Note: the demos use 16 stimuli and two simulated regions with 60 voxels each, built so that one region carries low-level image information and the other category information. Real data are noisier and need repeated measurements or cross-validated distances.
